# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

**Do not report security vulnerabilities through public issues, discussions or pull requests.**

Report them privately instead:

1. **GitHub Security Advisories (preferred):** open the repository's **Security** tab and choose **Report a vulnerability**.
2. **Email:** `contact@hononeko.app`

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- Affected versions or commits
- Any suggested mitigation

## What to Expect

- **Acknowledgement:** within 48 hours.
- **Triage & fix:** the issue is validated and fixed privately, then released as a patch version.
- **Disclosure:** coordinated public disclosure once a fix is available.
